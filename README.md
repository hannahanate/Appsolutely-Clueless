## Installing SQLite 

The frontend uses `expo-sqlite` for local database storage.

### Installation

1. Navigate to the frontend folder:

   ```bash
   cd frontend
   ```

2. Install the SQLite dependency:

   ```bash
   npx expo install expo-sqlite
   ```

3. Start the Expo development server:

   ```bash
   npx expo start
   ```

**Note:** Install `expo-sqlite` in the `frontend` project, not in the `backend` folder. Use `npx expo install` to install a version compatible with the project's Expo SDK.
